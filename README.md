# CinemaCatalog

Консольный каталог фильмов. После входа по имени и паролю программа показывает три карточки: предыдущий фильм, текущий и следующий. Карточки можно листать, выбрать фильм и добавить его в избранное.

## Библиотека

`cinema.h` и `cinema.c` — каталог фильмов на кольцевом двусвязном списке, пользователи и избранное. Функции ничего не печатают и не читают с клавиатуры. Программа в `main.c` только подключает эту библиотеку: карточки, меню и вход живут отдельно.

Сборка одной библиотеки для проверяющей программы — файл `cinema.c` (в нём нет `main`):

```bash
clang -std=c11 -Wall -Wextra -c cinema.c
```

## Сборка программы

Из корня проекта:

```bash
mkdir -p bin
clang -std=c11 -Wall -Wextra -o bin/CinemaCatalog main.c menu.c cinema.c render.c
```

## Запуск

Программу нужно запускать из корня проекта: она читает `Users.txt` и `Films.txt` из текущей папки.

```bash
./bin/CinemaCatalog
```

## Вход

| Имя   | Пароль | Роль           |
| ----- | ------ | -------------- |
| NiXbi | 1234   | администратор  |
| DiXer | 1234   | пользователь   |

Пустая строка вместо имени завершает программу. Слово `new` регистрирует зрителя: логин 3–20 символов (латиница и цифры), пароль 6–20 с заглавной, строчной и цифрой, номер карты — 16 цифр. Эти учетные записи заведены в файле вручную, поэтому пароль `1234` для них подходит, хотя для новой регистрации он слишком простой.

## Управление

1. Следующий фильм
2. Предыдущий фильм
3. Выбрать фильм и оформить билет
4. Добавить текущий фильм в избранное
5. Выход
6. Удалить фильм из каталога (только администратор)
7. Добавить фильм (только администратор)

Каталог зациклен: после последнего фильма снова идет первый. Избранное пишется в `favorites_<логин>.txt`.

## Данные

`Users.txt` — по строке на пользователя:

```text
логин пароль карта избранное админ
NiXbi 1234 5555555555554444 0 1
```

`Films.txt` — на каждый фильм пять строк: название, год, страны, жанры, рейтинг:

```text
Брат
1997
Россия
драма
8.3
```
