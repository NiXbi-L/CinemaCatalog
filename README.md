# CinemaCatalog

Консольный каталог фильмов. После входа по имени и паролю программа показывает три карточки: предыдущий фильм, текущий и следующий. Карточки можно листать, выбрать фильм и добавить его в избранное.

## Сборка

### macOS и Linux

Из корня проекта:

```bash
mkdir -p bin
clang -std=c11 -Wall -Wextra -o bin/CinemaCatalog main.c menu.c list.c render.c
```

### Windows

Откройте `CinemaCatalog.sln` в Visual Studio и соберите конфигурацию Debug или Release. Исходники в UTF-8, в проекте для этого включён флаг `/utf-8`.

## Запуск

Программу нужно запускать из корня проекта: она читает `Users.txt` и `Films.txt` из текущей папки (или из папки на уровень выше, если запускать `bin/CinemaCatalog`).

```bash
./bin/CinemaCatalog
```

## Вход

| Имя   | Пароль | Роль           |
| ----- | ------ | -------------- |
| NiXbi | 1234   | администратор  |
| DiXer | 1234   | пользователь   |

Номер карты из `Users.txt` проверяется алгоритмом Луна. Пустая строка вместо имени завершает программу.

## Управление

1. Следующий фильм
2. Предыдущий фильм
3. Выбрать фильм и оформить билет
4. Добавить текущий фильм в избранное
5. Выход

## Данные

`Users.txt` — пользователи, поля через пробел:

```text
id name pass is_admin card_num
```

`Films.txt` — фильмы. Год, страна, жанр и рейтинг стоят в конце строки, всё, что перед ними, считается названием:

```text
Брат 1997 Россия драма 8.3
Ирония судьбы 1975 СССР мелодрама 8.1
```
